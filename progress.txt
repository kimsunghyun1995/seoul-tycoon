## Codebase Patterns
- CharacterSystem uses PixiJS 8 with a ticker loop; LOD switching uses DETAIL_ZOOM_THRESHOLD to switch between dot and full figure rendering
- Tests mock pixi.js entirely (no WebGL in jsdom), so rendering logic changes don't need separate test coverage beyond existing canvas/render tests
- All visual dimension changes in CharacterSystem are in createCharacterGraphics, drawLegs, and the dot fallback block in the ticker loop
- SeoulMap.tsx contains SeoulSVG (inner component), DISTRICTS array, DISTRICT_LABELS, HAN_RIVER_PATH, MAJOR_ROADS, GYEONGGI_PATH constants
- SVG tests only check for element presence/text content, not colors - color/style changes are safe to make without breaking tests
