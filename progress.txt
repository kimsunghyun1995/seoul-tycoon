## Codebase Patterns
- maplibre-gl v5: import as `import maplibregl, { type Map } from 'maplibre-gl'`, use `new maplibregl.Map({...})`
- maplibre-gl mock in vitest: use `class` syntax (not arrow function) in `vi.fn().mockImplementation`; return `{ default: { Map: MockClass } }`
- maplibre-gl CSS: `import 'maplibre-gl/dist/maplibre-gl.css'` — mock in tests with `vi.mock('maplibre-gl/dist/maplibre-gl.css', () => ({}))`
- CharacterSystem and HotspotLayer temporarily removed from App.tsx — will be re-added in V4-3/V4-4 with geo-based coordinates
- Custom map style: `src/assets/map-style.json` uses OpenFreeMap vector tiles (OpenMapTiles schema). Import as JSON and pass as `style: mapStyle as any` to maplibregl.Map
- OpenFreeMap tile source: `{ type: "vector", url: "https://tiles.openfreemap.org/planet" }`, glyphs from `https://tiles.openfreemap.org/fonts/{fontstack}/{range}.pbf`
- Key OpenMapTiles source-layer names: landuse, landcover, water, waterway, transportation, building, place, water_name
- 3D buildings: use `fill-extrusion` layer type with `render_height`/`height` property for extrusion height
