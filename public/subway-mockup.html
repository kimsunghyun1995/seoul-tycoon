Design Concept
🚇 Nearby Stations
핫스팟 선택 시 BottomSheet에 가까운 지하철역 1~2개 표시. 좌표 기반 최근접 역 자동 매칭.
🌏 Bilingual (한/영)
역 이름을 한글 + 영문 병기. "가까운 역" = "Nearby Stations"
외국인이 지하철 앱에서 역 검색 가능.
⏱️ Real-time Arrival
서울 열린데이터 OA-12764 API 사용. 방향별 다음 열차 도착시간 + 칸별 혼잡도 표시. 1분 이내 = 빨간색 강조.
🚶 Walk Time
핫스팟에서 역까지 도보 시간 (직선거리 기반). 초록 pill로 눈에 띄게 표시.
🔀 Transfer Info
환승역은 복수 호선 뱃지 + "환승 Transfer" 태그. 호선별 색상은 실제 서울 지하철 색상 코드 사용.
🗺️ Map Overlay
지도 위에 지하철 노선을 얇은 색상 라인으로 표시. 역 위치에 작은 원형 마커. 기존 핫스팟 마커와 공존.
📡 Data Source
서울 열린데이터광장 — 같은 API 키 재사용
• OA-12764: 지하철 실시간 도착
• allorigins CORS 프록시 기존 인프라 활용
• 추가 비용: 없음
